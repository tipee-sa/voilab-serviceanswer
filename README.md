Voilab Service Answer
==========

Yet another means to standardize a service answer with error management.

A fork for modern days [![CI](https://github.com/tipee-sa/voilab-serviceanswer/actions/workflows/ci.yaml/badge.svg)](https://github.com/tipee-sa/voilab-serviceanswer/actions/workflows/ci.yaml)
==========

This is a fork of `voilab/serviceanswer` adapted for modern PHP development, which supports :

* PHP `8.1` <-> `8.5`

The following changes were applied to the dev dependencies :

* PHPUnit for unit tests
* PHPStan for static analysis
* Add GitHub Actions for continuous integration
